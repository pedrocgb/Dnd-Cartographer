# Gnomes — 2,000 name entries

Four lists of 500 names each · Compiled 6 October 2026 · UTF-8 Markdown

## How to use this collection

Choose a first name, optionally a second given name, and optionally a surname or clan name. **Middle names are optional** and are not asserted to be an established custom for every culture. Avoid repeating the same name within a generated full name. Gender labels describe this pool’s selection defaults, not restrictions on characters.

Each name is a separate table row. The **Name** column is the value to import; the remaining columns are metadata. Numbering restarts at 1 in every section. All four lists contain exactly 500 entries. Case, accents, spaces, and punctuation are normalized for duplicate detection across this file.

The pool combines a small set of D&D and Baldur’s Gate examples with original workshop, woodland, and whimsical constructions. Optional additional given names suit the app without requiring every gnome to follow one published naming custom.

**Composition: 25 published-reference entries + 1,975 original entries.** This is primarily an original expansion supported by a small sourced reference set, not a catalog of 2,000 canonical characters.

**Provenance:** `O` = original construction for this collection, not claimed to occur in a published work. Other codes point to references below. A sourced name can be an official naming example or a character’s name; it does not mean the generated NPC is that character. Incidental matches between original constructions and existing names elsewhere remain possible. No invented etymologies or translations are assigned.

The new names were assembled from species-specific sound palettes and compound-name vocabularies. Several names share roots, as names in a culture often do; no numeric padding or accent-only duplicates were used.
