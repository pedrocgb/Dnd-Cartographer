# 500 Hamlet Names

**Category:** Hamlet  
**Entries:** 500  
**Researched:** 9 October 2026

500 real names listed as hamlets in English county categories. Entries also matched to the same county's Domesday index are marked as recorded in 1086. All other entries have an unverified medieval date: a modern hamlet category alone is not proof of medieval origin. Modern spelling and hamlet classification are used.

Names are alphabetized and unique within this file after ignoring accents, punctuation and case. A historical place can appear in different category files; settlement roles and sizes changed over time. County labels identify the source context, not a claim about exact modern boundaries.
