**Category:** Village

500 real village names matched to a Domesday county index (1086) and a modern village listing. Spelling follows the retrieved index/category, usually a modern form, rather than necessarily the spelling written in 1086. Modern village status does not establish the settlement's precise medieval size.

Names are alphabetized and unique within this file after ignoring accents, punctuation and case. A historical place can appear in different category files; settlement roles and sizes changed over time. County labels identify the source context, not a claim about exact modern boundaries.
